# roza-legal

Public legal pages for the Roza app, served by GitHub Pages from `main`.

| Page | Use it for |
| --- | --- |
| `privacy-policy.html` | Play Console → App content → Privacy policy |
| `delete-account.html` | Play Console → App content → Data safety → Data deletion URL |
| `terms-of-use.html` | In-app legal links and the store listing |

The app source lives in the private `Rose-Valley-Labs/roza` repo. When app behaviour
changes what data is collected or shared, update these pages and their
"Last updated" dates in the same week.

The operator named here is NGN Consulting Corp. Change it to Rose Valley Labs, Inc.
once the company is formed and Roza has been assigned to it.
